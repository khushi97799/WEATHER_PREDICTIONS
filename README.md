# WEATHER_PREDICTIONS
# 🌦️ Weather Prediction ML Project

An ML project that predicts next-day temperature using real-time weather data and XGBoost.

---

# 🚀 Features

- 🌐 Live weather data (OpenWeather API)  
- 🧹 Data collection & preprocessing  
- 🤖 XGBoost ML model  
- 📊 Feature engineering (lags, rolling stats)  
- 🌍 Streamlit dashboard  
- 🔮 Next-day temperature prediction  

---

# 🛠️ Tech Stack

Python, Pandas, NumPy, Scikit-learn, XGBoost, Streamlit, Requests

# ⚙️ How to Run

```bash
python src/create_dataset.py
python -m src.train_model
python -m streamlit run app.py
```
